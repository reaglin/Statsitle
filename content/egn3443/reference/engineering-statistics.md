# Statistics in engineering: the big picture

| Idea | What it gives an engineer | Where in the course |
|---|---|---|
| Descriptive statistics | the center, spread and shape of the data in hand | Module 2 |
| Probability | the rules for chance events | Module 3 |
| Probability distributions | models for random quantities: binomial, Poisson, normal, … | Modules 4 and 5 |
| Sampling distributions | how much a statistic changes from sample to sample | Module 6 |
| Confidence intervals | a range of plausible values for a parameter | Module 7 |
| Hypothesis tests | a decision about a claim, with a known risk of error | Modules 8 to 10 |
| Regression | how one variable depends on others | Modules 11 to 13 |
| ANOVA | comparing several groups at once | Module 14 |

## Types of data

| Type | Values | Examples | Summaries |
|---|---|---|---|
| Numerical, continuous | any value in a range | length, strength, time | mean, median, standard deviation |
| Numerical, discrete | counts | defects, failures, calls | mean, median, standard deviation |
| Ordinal | ordered categories | condition rating 1 to 5 | median, mode |
| Categorical (nominal) | names | supplier, defect type | mode, counts, percentages |

## Sources of variation

Material, machine, method, measurement, environment and people. Variation from many small causes that are always present is **common-cause** variation; variation from a specific, identifiable event is **special-cause** variation (item 1.6).

## Statistical thinking

1. All work occurs in a system of interconnected processes.
2. Variation exists in all processes.
3. Understanding and reducing variation are keys to success.
