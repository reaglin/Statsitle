# Using Statistics+: keys, marks and menus

## Keys

| Key | Does |
|---|---|
| Ctrl+L | Show the Course |
| Ctrl+B | Show the Workbench |
| Ctrl+1, Ctrl+2, Ctrl+3, Ctrl+4 | The Learn, Example, Exercise and Reference tabs of an item |
| F1 | Help for the screen you are on |
| Ctrl+Z | Undo, in the Workbench |

## Marks in the list on the left

| Mark | Means |
|---|---|
| ✓ | complete |
| ◐ | started |
| ○ | not started |

## When an item is complete

| The item has | It is complete when |
|---|---|
| An exercise (a dataset) | Check my answers passes |
| Questions | you pass them (80 % on a module check) |
| Neither (a reading) | you press I have read this |

## The Learner menu

| Command | Does |
|---|---|
| Sign in… | Opens Who is learning?, to choose your name and type your PIN |
| Sign out | Saves your progress and locks your file |
| Back up my progress… | Saves a copy of your progress file, to a USB drive or a cloud folder |

On the **Who is learning?** screen: **New learner** (the first time), **Add learner from file** (a backup or a file from another computer), **Forgot my PIN** (needs your recovery code), and **Just the Workbench** (the calculator, with no progress kept).

## The Workbench's tabs

| Tab | Holds |
|---|---|
| Properties | The data and settings of the chosen analysis, and its results |
| Report | The results written up, to save as PDF |
| Plots | The figures |
| Code | The Python or R that gives the same results: Copy code, Save code as… |
| Instructions | How and when to use the chosen analysis (F1) |
