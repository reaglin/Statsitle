# The course report template

Every EGN3443 assignment is handed in as a report with these sections, in this order.

| Section | Contents |
|---|---|
| Title | Title (may be centered), name, date, submitted for or to |
| Introduction | Brief: a single sentence is sufficient |
| Problem statement | The core of the assignment's problem, usually copied; leave out outcomes and grading policy |
| Methodology | How the problem was approached and solved: the statistical method, the decisions made, and why. Equations are not always needed |
| Conclusions | The answer to what the problem statement asks; plots when they are part of the answer |
| References | Only when the problem statement asks for sources |
| Appendices | Code, hand calculations, and anything else that takes the reader from the methodology to the conclusions |

## A checklist before you hand it in

- Does the first sentence of the conclusions answer the question asked?
- Does every number have its unit, and a sensible number of decimals?
- Does the methodology name the method and say why it fits the data?
- Is the code, with its output, in the appendices?

## Where the pieces come from in Statistics+

| Section | Workbench tab |
|---|---|
| Methodology | Instructions (F1); the methods cited on the Report tab |
| Conclusions | Properties and Report (results), Plots (figures) |
| Appendices | Code (Copy code, Save code as…); the Report tab's code appendices |
