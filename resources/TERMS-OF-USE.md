**A statistic is not a conclusion.** Statistle implements standard methods — the t and z tests,
the chi-square and F tests, Shapiro–Wilk, Levene, Mann–Whitney, Wilcoxon, least-squares
regression, and analysis of variance — and names the method behind every result so it can be
checked. Each method rests on assumptions about the data, and Statistle cannot know whether your
data satisfies them, whether your sample was drawn properly, or whether the question you are
asking is the one the test answers. Results are an aid to analysis and to learning, not a
substitute for judgment. Verify them independently before relying on them for any decision.

**The generated code is a starting point.** The Python and R that Statistle writes are meant to
be read, understood, and run by you. Statistle does not execute them and does not check the
environment they will run in. Review any generated code before running it, as you would anyone
else's.
